# TB331FC 救砖：900E → 9008 EDL 教程（实测）

> 现状：USB 为 `Qualcomm HS-USB Diagnostics 900E (COM3)`  
> 目标：`Qualcomm HS-USB QDLoader 9008 (COMx)`，再用 QFIL 整包刷 ZUI  
> 原则：**不改** `E:\类\刷机\联想\TB331FC\` 原包，只读使用

---

## 一、先分清 900E / 9008

| 模式 | 设备管理器名称 | PID | 能否 QFIL 整包 |
|------|----------------|-----|----------------|
| **900E** | `Qualcomm HS-USB Diagnostics 900E` | `05C6:900E` | ❌ 还在 **Sahara**，装不进 firehose |
| **9008** | `Qualcomm HS-USB QDLoader 9008` | `05C6:9008` | ✅ 标准 EDL 线刷 |

实测：`fh_loader` 对 COM3 报  
`target is in SAHARA mode / 请先 QSahara 送 DeviceProgrammer` —— 900E 时送 firehose 会卡死或失败。

---

## 二、开始前

1. **电量**：截图显示 **0%**。先用原装/合格充电器充 **20 分钟以上**（0% 时 9008 极易掉线）。  
2. 驱动：QPST / `9008 驱动` 目录已装好。  
3. 线材：尽量用原装 USB 线、接主板后置口（不要扩展坞）。  
4. 材料（只读）：  
   - `...\TB331FC_ZUI_16.0.544\`（完整线刷包 + `prog_firehose_sm6225_ddr.elf` + rawprogram）  
   - `...\9008 工具箱\WuXingEdl.exe`、`tool\QSaharaServer.exe`、`fh_loader.exe`、`QFIL.exe`

---

## 三、进入 9008（推荐顺序）

### 方法 A：官方组合键（作者写明「fastboot 进不去 EDL」）

1. **长按电源 15～30 秒** 完全关机（黑屏后可拔 USB）。  
2. **同时按住「音量+」和「音量−」**（两只手都按住，不要松）。  
3. **再插入 USB**（另一只手或别人帮忙）。  
4. 听到「叮」后松开按键。  
5. 设备管理器应出现：  
   `Qualcomm HS-USB QDLoader 9008 (COMx)`  

若仍是 `Diagnostics 900E`：拔线 → 再彻底关机 → 重来；两键必须**先按住再插线**。

### 方法 B：从 900E 再强制断电

1. 拔掉 USB。  
2. 长按电源 30 秒以上（放掉余电）。  
3. 等 1 分钟，再按 **方法 A**。

### 方法 C：工具 `WuXingEdl.exe`

1. 运行 `E:\类\刷机\联想\TB331FC\9008 工具箱\WuXingEdl.exe`  
2. 按工具提示选 9008 / 紧急下载（界面为中文）。  
3. 看设备管理器是否变成 **QDLoader 9008**。

### 方法 D：EDL 短接 / EDL 线（硬件）

- 仅在 A/B/C 都失败时：拆机找测试点（需教程图，风险自担），或用 EDL 线。

---

## 四、到 9008 后：QFIL 整包刷回 ZUI

### 方式 1：图形 QFIL（稳）

1. 打开 `tool\QFIL.exe`  
2. **Select Port** 选中 `9008 COMx`  
3. **Select Programmer** → `prog_firehose_sm6225_ddr.elf`  
4. **Load XML** → 选 `rawprogram0.xml`（以及工具要求的 `patch0.xml`）  
5. 点 **Download / Load**，等待完成（含 super 多镜像，时间较长）  
6. 完成后拔线开机  

### 方式 2：命令行（我可代跑）

```bat
cd TB331FC_ZUI_16.0.544\tool

REM 1) 送入 firehose（9008 下有效）
QSaharaServer.exe -s 13:prog_firehose_sm6225_ddr.elf -p \\.\COM3

REM 2) 按 rawprogram 刷写
fh_loader.exe --port=\\.\COM3 --search_path=..\image --sendxml=rawprogram0.xml --memoryname=ufs --zlpawarehost=1 --noprompt --showpercentagecomplete
```

> 若只刷关键分区，可改 `sendxml` 为只含 boot/recovery/vbmeta/super 的 xml（需按包内 rawprogram 顺序）。

---

## 五、刷完后

1. 拔线，长按电源开机（首启较久）。  
2. 若仍不开机 → 再 9008 整包刷一遍。  
3. **暂不要再刷 TWRP**；等系统稳定后再谈 recovery。

---

## 六、为什么不建议现在修 TWRP

| 问题 | 说明 |
|------|------|
| `fastboot boot` | 此 bootloader **不支持**（unknown command） |
| `reboot recovery` | 曾 `Load Error` |
| GKI 设备 | recovery 无内核，依赖 boot；改 recovery 易牵连 boot |
| 当前 | 优先 **原厂 ZUI 救活**，TWRP 后置 |

---

## 七、一键检查（进 9008 后）

```powershell
# 设备管理器应为 9008
Get-PnpDevice -PresentOnly | ? { $_.FriendlyName -match '9008|900E|QDLoader' }
```

- 出现 **QDLoader 9008** → 告诉电脑旁的我，我继续跑 QFIL/fh_loader  
- 仍是 **900E** → 重复第三节，或先充电再试
