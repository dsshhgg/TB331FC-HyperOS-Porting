## F. 沟通与证据规矩（m02359 / m02368）
12. **做事要讲证据**（m02368）。汇报技术结论必须分「观测事实 / 推断 / 未知」三栏：

    - 推断：必须写明反证条件（什么观测结果会推翻它）。
    - 未知：直接写不知道，并给出拿到答案的具体手段。
13. **不许用「唯一 / 必然 / 肯定是」**，除非有对照实验；未做对照只能写「前置条件之一」（m02359 就是因为我写了“唯一门槛”被质疑）。
